# WorkBuddy 账号模型与官方积分规则

账号管理 → 模型 → 查看模型，展示当前所选 WorkBuddy 账号的官方模型目录和积分倍率。国内版与国际版根据账号的 `options.realm` 分别查询，使用该账号自身的凭据及出站代理。

## 展示规则

- 原先的 relayAI 输入/输出金额已从账号模型卡片移除。relayAI 的模型价格配置仍在模型广场，用于自身计费；它不能代表 WorkBuddy 积分扣费。
- `x0.00`、`x0.00 credits` 等明确为零的倍率显示“免费 · 不扣积分”。
- 正数倍率显示“扣积分 / 倍率 ×N”，同时保留官方原始标识。倍率不是每次固定扣 N 分，实际扣分还与请求用量有关。
- 上游未返回或无法识别的计费标识显示“扣费规则未知”，不把缺失值当作免费，不用内置价格猜测。
- 保留账号实时清单中的收费变体，不因存在免费兄弟型号而隐去收费档。过滤非聊天通道，遵守账号模型白名单，不受分组对外发布白名单影响。
- 没有已同步的 relayAI 模型目录时，WorkBuddy 账号仍能打开实时查询。

## 实时性

`GET /api/v1/accounts/{id}/models` 为管理员接口，经 Go 后端转发到网关，再请求 WorkBuddy 官方 `/v3/config`。请求直接使用账号凭据；不读取桌面缓存、内存路由矩阵、数据库目录或内置快照。接口响应禁止缓存，上游请求附带不缓存请求头和时间戳。

每次打开弹窗、手动刷新、回到可见窗口时重新查询；弹窗可见期间每 30 秒查询一次。关闭弹窗取消浏览器请求并停止轮询，隐藏页面不继续轮询。账号切换会清空前一个账号的结果，失败时显示错误与重试入口，不降级展示旧价格。卡片显示成功查询时间。

这是按需查询与轮询，并非上游推送；页面展示的是该次查询时官方返回的值，无法保证请求结束后价格永不变化。此功能不调用对话生成接口。

## 峰谷与来源

参考 `dynamic-island` 的 WorkBuddy 模型目录解析和免费/倍率展示。其现有实现会读取桌面缓存，并在部分元数据缺失时合并快照，因此本项目为实时展示新增独立查询路径，没有沿用缓存回落。

该接口已识别的计费字段是每个模型的 `credits`。目前没有经过验证的独立峰谷时间表或完整积分计费公式；不按模型原厂 API 价格计算 WorkBuddy 的峰谷积分，也不根据机器时间自行打折。当前倍率随下一次实时查询更新；若上游只给出复合文本，保留原文并标为未知，避免误报免费。模型原厂公开 API 单价的档位与来源另见 [内置价格说明](builtin-model-prices.md)。

2026-10-29 使用已有账号分别请求国内站和国际站，均返回 HTTP 200 / code 0。该次返回中，国内 `deepseek-v4.1-flash` 为 `x0.11`，国际同名模型为 `x0.00`，国际 `deepseek-v4.1-flash-sg` 为 `x0.03`；两区 `glm-5.3` 均为 `x0.69`。这些仅是当次核对结果，没有写成显示默认值。该次响应没有发现独立峰谷规则字段。

## 验证与部署

回归测试验证每次调用都会访问上游、免费变收费能立即更新、缺失值保持未知、上游失败不使用快照、带斜杠账号标识正确转发。

更新源码后执行：

```bash
sudo docker compose up -d --build --no-deps backend gateway web
```

无需数据库迁移或重新导入账号。
