# 使用记录错误详情

使用记录中的失败、上游断流、客户端中断、未调度状态支持悬浮查看详情，也支持键盘聚焦和触屏点击。成功记录不显示错误入口。

详情包含网关请求 ID、已保存的失败原因，以及上游返回正文（如果存在）。合法 JSON 会格式化；HTML 和其他文本按原文显示，不执行 HTML。长内容在浮层内滚动，可选择复制；Escape 或点击外部关闭。

## 错误记录

- 继续使用 `usage_logs.error_detail` 和现有使用记录 API，不需要数据库迁移。
- Chat Completions、Responses、Anthropic 三种入口均保留可获得的上游错误正文，覆盖流式和非流式请求。
- 流式错误事件标记为 `upstream_aborted`，避免携带错误事件的请求被记成成功。OpenAI 兼容的 SSE `error` 信封也会被识别。
- OpenAI 兼容错误正文最多保存 16 KiB，并在截断时显示提示；不补造上游未返回的信息。
- 请求建立上游连接前失败时，沿用现有的 `rejected` 记录，也可查看详情。存在重试时，这里的错误详情是请求最终留下的错误，不是每次尝试的完整追踪。
- 历史记录只显示已经保存的内容；未保存详情或曾被截断的内容无法补回。

## WorkBuddy 账号限制

结构化错误码 `11140`（数字或字符串）识别为 `AccountRestricted`，显示“账号存在异常行为，已被上游限制使用”，保留原始 `displayMsg`、`displayTips`、`requestId` 等字段，不再误报为内容审核。此错误继续立即结束当前请求，不自动推断永久封禁、恢复时间或改变账号启停状态。

额度刷新任务的 HTTP 401 属于后台授权失败，不能据此认定账号被封；它不是模型调用，不作为一条推理使用记录插入。
