# 任务页成长数据刷新

任务页切换账号会重新请求渠道的实时任务快照，顶部加油站能量、连续登录及每日动作按所选账号展示。切换国内/国际版本时重新选择对应版本的渠道和全部账号，旧请求被取消，晚到的旧响应不会覆盖新页面。

“全部账号”模式只在所有账号能量都可读取时显示合计；部分账号失败时提示选择账号查看原因。连续登录天数不做累加，需选择一个账号查看。

快照接口响应设置 `Cache-Control: no-store`；前端及成长接口的只读请求附加禁用缓存的请求头。刷新按钮与账号切换均重新查询，不用本地旧值补齐失败的字段。加载过程中，统计条和任务表格通过 `MyBox` 显示加载状态。

成长快照的三个只读接口并行查询，每个接口最多等待 8 秒，各自失败不会将其他接口的成功数据清空。`energyError` 与 `streakError` 将 HTTP 错误、业务错误、超时、字段缺失透传到页面；数值缺失仍为 `null`，真实的 `0` 正常显示为零。错误说明过长时可悬浮查看浏览器提示。

这次修复不改变上游接口地址、登录凭据或数据库结构。若更新后仍提示 HTTP 401，表示这次成长数据查询的授权未被上游接受，需要结合当前账号凭据和上游实际返回排查；重新请求不保证能绕过上游授权失败。

## Docker 更新

应用代码变更后，在包含 `compose.yaml` 的项目目录执行：

```sh
sudo docker compose up -d --build --no-deps backend gateway web
```

无需重新导入账号或迁移数据库。
